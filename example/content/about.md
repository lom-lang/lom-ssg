## About this site

Built with `lom build.lom -- site.json`.

### Facts

1. Zero third-party crates in the language toolchain
2. Markdown rendered by a recursive-descent parser
3. Output is plain static HTML

### Non-features

- no JavaScript
- no template engine beyond variable substitution
- no directory crawling - the page list lives in site.json
